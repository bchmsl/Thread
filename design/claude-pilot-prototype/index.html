Thread pilot prototype

A clickable design prototype of the personal workspace: Today, Topics, Notes, Inbox, read-only Jira and pull requests, search, settings and Trash. Open the app, or jump to any surface or state below.

Open Today Start at sign-in README

All people, tickets, repositories and pull requests are invented. Changes are saved in this browser only. Links marked with a dot switch on a simulated state, which stays on until you change it in Demo controls or reset the demo.

Journeys to try

Each one starts from the example workspace. Reset the demo first for a clean run.

Capture, triage, finish

  1. Press C, type a Task, keep “Inbox, sort later”, press Enter.
  2. Open Inbox, pick a Topic in the triage panel, choose Move.
  3. Open that Topic and tick the Task.
Start

Write offline, resolve a conflict

  1. Open a Note, format a line as a heading or checklist.
  2. Go offline in Demo controls, keep typing, watch the save status.
  3. Go online, then create a conflict and choose a version.
Start

Find a ticket and link it

  1. Search Jira for “receipt” and open a result.
  2. Choose Link to Topic and pick one or more Topics.
  3. Open a linked Topic from the ticket.
Start

Change a status

  1. Open the paused Topic and set its status to Active.
  2. See it on Today under Active Topics, and in the Active lane on the Board.
  3. Rename or delete a status in Settings and see the Board follow.
Start

Delete and restore a Note

  1. Open a standalone Note and choose Move to Trash.
  2. Open Trash and restore it. The message says where it went back.
Start

Search and go

  1. Press Cmd or Ctrl + K and type “mapper”.
  2. Use the arrow keys and Enter to open a result. Escape closes.
